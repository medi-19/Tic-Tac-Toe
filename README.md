Tic Tac Toe (Green vs Red)
A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.
Instead of X and O, players use colors: Green (Player 1) and Red (Player 2).

Features:
3×3 game board
Two-player local gameplay
Player 1 → Green
Player 2 → Red
Detects win and draw
Restart button

How to Play:
Player 1 (Green) starts the game.
Players take turns clicking on an empty box.
The first player to get three boxes in a row, column, or diagonal wins.
Click Restart to play again.

Built With:
HTML – structure
CSS – styling
JavaScript – game logic
